What happened

The Associated Press, carried by WTOP and dated September 13, 2026, reports that organizers in Bucharest set a Guinness World Record for the longest table made from recycled materials: the Uniting Table stretched 5,055 meters (about 3.1 miles) along Unirii Boulevard. Bloom The World Association led the project. The prior mark was 2,782 meters, set in Alba Iulia on the same calendar date a year earlier. Fundraising supports a pediatric psychiatry facility at Obregia Hospital, with the Metropolis Foundation’s project pegged around 16.5 million euros.
